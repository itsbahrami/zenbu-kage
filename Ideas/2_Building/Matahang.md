# Matahang

- متهنگ = متن + آهنگ
- A simple library of musics...
- Each music:
  - Generated Cover Art
  - Optional palette
  - Optional AppleMusic/Spotify link
  - Optional anime/movie link
  - Optional singer name
  - Title
  - Language (FA / EN / JA / AR)
    - Direction (FA & AR = RTL - EN & JA = LTR)
    - Font (FA & AR = Vazirmatn - EN & JA = Klee One)
  - PRINT VIEW! for printing
  - A place to write the lyrics... (with language switch that switches font & layout)
  - CRUD...
  - Searching & filtering
  - Tags...
