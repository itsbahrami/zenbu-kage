# Just Build It

1. DUMP: Get it out of your head.
2. PEEK: Google for existing stuff. If found sth, use it, if not, continue.
3. BUILD: Write the simplest version to lesses the pain.
4. DECIDE: to KEEP or to CANCEL.

- File naming convention:
  - Example: `260829_BrowserExtension.md`
  - `26`: Year 2026
  - `08`: August
  - `29`: Day of the month
  - `_`: Separator
  - `BrowserExtension`: Name of idea in `PascalCase`
